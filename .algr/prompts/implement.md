# algr リポジトリでの決まり

- PR は作らず、push もしない。ジョブを始めたときのブランチ（統合ブランチ。PR で main に入る）から `algr/<タスク ID>` のブランチを切り、そこにコミットする（やり直しなら同じブランチに足す）
- 結果の `pr` にはブランチ名（例：`algr/I1`）を返す
- `uv run pytest -q` と `uvx ruff check src tests` を通す
- イベント名やペイロードを変えたら README の表も直す（CLAUDE.md）
- 終わったら、ジョブを始めたときのブランチに戻る
- 前の回のジョブが消えて出し直された（再起動など）と分かったら、前の回の続きとして扱う。始めたときに作業ツリーが `algr/<タスク ID>` にいて書きかけが残っていたら、それを捨てずにそのブランチで続ける。
  このときの「ジョブを始めたときのブランチ」は `algr/<タスク ID>` ではなく統合ブランチ（`algr/` で始まらない、そのブランチの切り元）なので、終わったらそこへ戻る
