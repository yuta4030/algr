# UI の改善メモ

`algr ui`（`src/algr/ui.py`、`ui.html`）を使っていて気づいたことを貯め、まとめて 1 件に起票する。起票したらここから消す。

## 未決事項に答える

- **未決事項の論点と選択肢を出す**：詳細パネルは本文と推奨しか出さず、`topic` と `options` を捨てている。何を聞かれていて、どれから選ぶのかが分からない
- **一覧のカードで問いが途切れる**：未決の問いの本文をつないで 1 行に出すだけなので、途中で切れる。件数と論点を出すなど、何を聞かれているかが一目で分かる形にする
- **UI から回答できるようにする**：「回答する」ボタンは未実装で、`algr answer` のコマンドを見せるだけ。選択肢を選ぶ、推奨を受ける、自由に書く、のどれでも答えられるようにする。操作は Engine のメソッド（`resolve`）を通す。答えるたびに起票が走り直すので、1 件の問いはまとめて送れるようにする
